# Vactory Hreflang

Maps each enabled Drupal language code to a configurable hreflang value without
changing language URL prefixes or stored content language IDs.

## Configuration

1. Enable the module.
2. Visit `/admin/config/regional/vactory-hreflang`.
3. Assign an hreflang value to every enabled language and save.

For a Moroccan site, typical mappings are `ar` to `ar-MA` and `fr` to `fr-MA`.
The `x-default` tag generated by the Hreflang module is left unchanged.

## Decoupled output

The module adds a read-only `internal_hreflang` computed field to nodes. It is
available to JSON:API and contains one object per accessible translation:

```json
[
  {
    "rel": "alternate",
    "hreflang": "ar-MA",
    "href": "https://example.com/ar/example"
  }
]
```

When `BASE_FRONTEND_URL` is set, links use that origin. Otherwise, links use
Drupal's absolute canonical URLs. The field also exposes `x-default` when it is
enabled in the contributed Hreflang module.
